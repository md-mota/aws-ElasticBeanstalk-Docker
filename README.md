# AWS Elastic Beanstalk Docker Deployment 

This project demonstrates how to containerize a simple web application using Docker and deploy it to AWS Elastic Beanstalk using a managed environment. 

---

## Workflow Diagram 

![Elastic Beanstalk Docker Workflow](https://github.com/md-mota/aws-ElasticBeanstalk-Docker/blob/master/workflow-diagram.png) 

---

## Project Overview

This project shows how to: 
- Build a Docker image from a simple web application
- Run the container locally for testing
- Configure Elastic Beanstalk to deploy a Dockerized application
- Use `Dockerrun.aws.json` for container deployment
- Manage application versions and environment settings in AWS
